# Codex Micro mobile derivative

This public derivative combines the native Codex Micro renderer-event bridge
with an original SwiftUI iPhone control surface.

Upstream:

- Project: `dazer1234/codex-stream-deck`
- Source revision: `6d7d14b9c966de305617a43a7ac22c7034ac075e`
- License: MIT

The original `LICENSE` file and upstream copyright notice are preserved.
Local changes include the iPhone interface, widgets, onboarding, mobile pairing,
authenticated relay behavior, product-facing Codex Micro naming, and portable
Apple signing configuration. Internal relay identifiers remain compatible with
the upstream Mac launcher and QR pairing protocol.

This remains an unofficial integration built on undocumented Codex desktop
internals. It is not made, supported, or endorsed by OpenAI or Work Louder.
